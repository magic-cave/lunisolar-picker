Add `DateTimePicker`: one field and one popover for a date and a time, with values in `YYYY-MM-DDTHH:mm` (plus `[u-ca=dangi]` for lunar entries). Add the `DateTimeString` value type, the `DateTimeField` part and `useDateTimeField` hook, `min`/`max` on `TimePicker`, `TimeField` and `TimeList`, and the `--lsp-control-size` theme variable for input height. The `before-min` and `after-max` messages no longer mention dates, since they now also describe times.
